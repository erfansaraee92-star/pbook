# 🔐 pbook — Offline Password Manager

pbook is a minimal, offline, encrypted password manager written in Python.
It is built for learning purposes, privacy-focused users, and people who do not trust the cloud.

No accounts  
No internet  
No cloud  
Just you and your vault
--
How to use:
First time that you enter the app.a folder called secure_vault should be created.DO NOT DELETE IT.
First time that you enter the app you need to make a master password.the other times that you enter the app
you need to enter that master password.

---

## ✨ Features

- Strong encryption (Fernet / AES-based)
- Fully offline
- Single Master Password
- Simple graphical interface (Tkinter)
- Secure local storage
- Single-file application
- Lightweight and fast
- Easter egg included
